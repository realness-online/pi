# Fork tooling

Run from `work/pi`. Read [FORK.md](FORK.md) before updates or activation.
The harness's `npm --prefix ../.. run pi:reinstall` reinstalls its reviewed pin; it does not update this fork.

- `npm ci --ignore-scripts`: install; `npm run hydrate:model-data`: prepare fresh worktrees.
- `npm run check`: source checks, including formatting writes.
- `npm run build:offline`: build before subprocess session tests.
- From `packages/coding-agent`, `npm test -- test/session-reader.test.ts` runs a focused test.
- Repeat session-format tests with `PI_SESSION_FORMAT=jsonl` and `html.gz`.
- `npm run pack:packages -- --out <harness-artifacts-path> --skip-build`: pack built packages.
- Use the consumer install and activation procedure in `FORK.md`; preserve reviewed dependency versions.
- Preserve the old selected install. Removing a marker restores the checkout pin, not the previous fork.
- Verify installed entry points, session decoding, memory search, and rollback before activation.
