# Fork tooling

Read `FORK.md` before an update. The harness's `npm run pi:update` reinstalls
its reviewed runtime pin; it does not advance this source fork.

- Install: `npm ci --ignore-scripts`.
- Fresh worktree model data: `npm run hydrate:model-data`.
- Source checks: `npm run check` (includes formatting writes).
- Build: `npm run build:offline` before subprocess session tests.
- Focused tests, from `packages/coding-agent`:
  `node ../../node_modules/vitest/dist/cli.js --run test/session-reader.test.ts test/session-compaction.test.ts test/session-compressed-storage.test.ts test/session-gzip.test.ts test/session-html.test.ts test/session-id-readonly.test.ts test/session-manager/custom-session-id.test.ts test/suite/agent-session-runtime.test.ts`
- Repeat session tests with `PI_SESSION_FORMAT=jsonl` and `html.gz`.
- Pack: `npm run pack:packages -- --out <harness-artifacts-path> --skip-build`.
- Wire a consumer: `node scripts/use-local-packages.mjs --manifest <manifest> --consumer <directory> --package @earendil-works/pi-coding-agent`.
- Derive the consumer lock from `packages/coding-agent/install-lock/`; keep reviewed dependency versions.
- Verify installed SDK, CLI, read-only decoder, public memory search, and rollback before activation.
- Preserve the old selected install. Removing a marker returns to the checkout pin, not the old fork.

The reviewed 1.2.0 update preserves custom compressed sessions and supports an
unfinished final HTML row in the read-only decoder. Evidence and isolated
verification scripts: `../../artifacts/pi/review-v1.2.0/`.
